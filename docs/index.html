Full Stack Engineer & Computer Science Teacher

Billy Rebecchi

I build tools that make computing feel less like magic — classroom game engines, Python in the browser, and the occasional Game Boy cartridge.

I've been building for 20 years and am a big fan of reinventing the wheel; how else would people learn to build wheels? I've spent the last 10 years building tools to help teach Computer Science in school and participating in game jams. I'm a huge proponent of low-level first principles and believe we should be teaching digital logic and Assembly in classrooms before ever touching higher level languages.
